# 🔥 최종 프로젝트 — 교육 상품 랜딩 클릭 캠페인

> 원문: [최종 프로젝트 (Notion)](https://app.notion.com/p/d7f3cf5f9fba82ee838e012d2d64f77c) · [교육 상품 랜딩 클릭 캠페인 프로젝트 (Notion)](https://app.notion.com/p/4013cf5f9fba82d196c68100fd2535fb)

## 목표
파이어 클럽의 금융·투자 교육 상품 4개 중 1개를 골라, Meta·구글 검색광고로 **자체 제작 랜딩페이지**에 방문자를 모으고 **CTA 클릭(라이브클래스 상품 상세페이지 이동)** 전환을 만들어 냅니다.
광고 소재 제작 → 광고 운영 → 데이터 분석 → 성과 개선의 전체 사이클을 경험합니다.

※ 실제 구매와 매출은 측정하지 않습니다.

## 전환 퍼널
광고 노출 → 광고 클릭 → 랜딩페이지 방문 → **CTA 클릭 (핵심 전환)** → 라이브클래스 상세페이지

## 핵심 KPI
활성 사용자 수 · 광고 CTR · CTA 클릭수 · CTA 전환율(CVR) · CTA 전환당 비용(CPA)

- CVR = CTA 클릭이 발생한 세션 ÷ 전체 랜딩페이지 세션 × 100
- 목표 수치는 [02_campaign_plan/kpi.md](02_campaign_plan/kpi.md)에 적습니다.

## 예산과 운영
- 팀당 **40만원 한도**이며, 1·2차에 자유롭게 나눠 씁니다. 카드 수수료가 광고비의 최대 10%까지 붙을 수 있으니 미리 반영하세요.
- Meta는 강사님 비즈니스 포트폴리오로 운영하며 팀당 2명이 초대됩니다. 같은 IP를 쓰므로 팀끼리 세팅 시간이 겹치지 않게 하세요.
- 소재는 **차수별 5개 이상** 만듭니다. 캐러셀, 숏폼, 단일 이미지를 섞어 쓰고, 단일 이미지는 최대 3개까지만 씁니다.
