# 광고 소재

## 형식 (반드시 준수)
- 캐러셀 / 숏폼 / 단일 이미지 (전부 단일 이미지 X, 단일 이미지는 차수별 최대 3개)
- 차수별 최소 5개 이상 제작·운영

## 파일명 규칙: `N팀_N차_소재유형_번호`
- 예: `1팀_1차_숏폼_01.mp4`, `1팀_2차_캐러셀_01_01.png`
- 캐러셀은 소재 번호 뒤에 카드 순서 번호 추가
- 캐러셀: PNG / 숏폼: MP4

## 소재별 카피 (검수 시 필수)
| 소재 | 기본 문구 (Primary Text) | 제목 (Headline) | 설명 (Description) | 음원 |
|---|---|---|---|---|
| | | | | |

## 사전 체크
- [ ] 수익 보장·과장 표현 없음 ("무조건", "100%" X)
- [ ] 개인 특성 직접 지칭 없음
- [ ] 광고 목적·운영 주체 명시
- [ ] 타사 로고 / 저작권 폰트·음원 없음
- [ ] 텍스트 비중 과다 아님
- [ ] AI 레드팀 사전 점검 (선택)
